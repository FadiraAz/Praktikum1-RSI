## Deskripsi Project
Untuk project RSI kami, kami akan membangun sistem informasi berbasis web untuk membantu 
mitra kami, CV. Barokah Globalindo, yang bergerak di bidang penyedia sarana pendidikan 
seperti buku sekolah, buku K13, ATK, ALPER, laptop, dan elektronik. Sistem ini dirancang 
untuk membantu mitra melacak stok produk serta mencatat dan memantau hasil penjualan 
secara lebih terstruktur dibanding pencatatan manual.
